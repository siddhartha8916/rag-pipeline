⚡ Query Strategy

🚀 Simple Query Strategy:

• Fast execution with single optimized SQL query

• Best for straightforward analysis and reports

• Example: "Show top 10 products by sales"

📊 Multi-Query Strategy:

• Generates 3-5 focused subqueries instead of complex JOINs

• Prevents infinite-running queries and performance issues

• Creates comprehensive dashboards with cross-data insights

• Example: "Generate business intelligence dashboard"

💡 Choose the right strategy:

• Use Simple Query for basic reports and quick analysis

• Use Multi-Query for complex analytics requiring data from multiple sources
